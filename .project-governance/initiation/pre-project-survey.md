# Xkeeps-Extension：公开分发副本准入准备

本报告由公开证据重新编写，准备 JinHanAI/Xkeeps-Extension 的正式建仓；当前没有创建远端、公开仓库、部署官网或发送社交内容。它是现有 Xkeeps 的公开分发副本，不是重新开发另一款产品。

## 目标、范围与用户

帮助使用桌面 Chrome 的个人用户保留、搜索和导出自己的 X 收藏与点赞；让普通用户免费安装，让开发者检查实现与参与维护。品牌归属 JinHanAI，保留 xarchive 和第三方版权。品牌影响力是目标，采用人数、转化与增长尚无证据。

范围限定扩展源码、合成测试、公开使用/隐私/贡献文档、构建与 CI，以及必要的脱敏准入证据。排除开发者私人数据、账号凭据、内部日志、网站部署配置、营销工作文件及 Xkeeps 私有开发提交。用户确认了仓名，公开仓库、更新官网、发布 X 均仍需另行确认。

复用 2026-09-30（东八区）原项目调查的上下文、现有方案、真实行为与替代方案四类研究，原文件不修改、不公开。证据适用于同一产品问题；本轮只增补公开分发和隐私隔离决策，不声称获得新的用户访谈或采用证据。

GitHub collector 搜索记录与四份 API 快照保持原字节、原哈希、原采集时间 2026-09-29 UTC；原有效期上限为 2026-10-28T16:38:17+00:00。2026-10-22 的重新采集遇到 HTTP 403 / IncompleteRead，未产生可替代的完整快照。当天只读打开四个公开仓库页面，确认页面可访问；这不是搜索结果/API 数据的刷新，不将历史星标、最近提交或许可证状态冒充今日 API 核验。若到建仓时有效期已过、上游许可/来源出现变化或路径改变，重新调查与校验。

## 决策：fork / new_repository

沿用 xarchive 公共基线 ae9d0263617a200ce142e64fb2ddc6301ebf19cf 和它已经公开的祖先；随后应用经独立复核的干净 Xkeeps 快照。不复制、合并或推送 Xkeeps 私有仓分支、标签与开发历史。这个方案替代先前的无历史发布建议，不改变真实代码来源。

最小差异是现有按账户隔离的收藏/点赞归档、搜索、多格式导出与中英文交互；公开分发不额外承诺完整历史采集、自动迁移或商业可用性。继续保留 MIT LICENSE、Dexie 与 helper notices；只承诺已核验的许可归属，不把开源当作全面法律或安全认证。

拟议公开范围在 111 个应用快照文件之外新增：公开上游历史、从零重写的脱敏准入报告/manifest、原始公共 API 快照及必要校验器/CI。该范围尚未获准公开。原内部立项报告、验收数据和工作路径绝不作为公开证据复制。提交署名仅用经验证的 JinHanAI 与 GitHub noreply 身份；本轮不修改原提交作者或历史。
