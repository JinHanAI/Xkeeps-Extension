# Xkeeps 完整使用手册

[返回中文首页](../README.zh-CN.md) · [English](../README.md)

主页面分为首页、浏览、账号和设置。首页更新和下载收藏或点赞；浏览页搜索已保存的内容；账号页管理各账号的存档；设置页管理定时更新、文件位置、语言和使用记录。

## 更新内容

在首页选择“收藏”或“点赞”。两类内容按账号独立保存，同一帖子可以同时属于两类。

- **全部更新**：首次使用或需要检查较早内容时使用。检查 X 返回的内容页面；收藏还会检查文件夹。
- **近期更新**：获取近期页面，遇到整页已有内容后停止。不检查较早内容的变化和文件夹。
- **暂停更新、继续更新、停止更新**：更新时保持页面打开。停止会保留已取得的部分结果，并显示未完成状态。
- **更新结果**：显示总条数前后变化、新增和更新条数，以及时间和用时。已有内容不会因为本次未出现而删除。
- **导入存档**：选择 JSON，核对账号和变化后确认保存。原文件不会被修改；CSV 和 Markdown 仅供预览。

X 的登录、访问限制和可见范围会影响结果。操作完成不代表每条收藏都已取回，请核对结果说明。

## 下载内容

在首页选择“下载收藏”或“下载点赞”的内容范围、时间范围和下载选项。

- **全部内容**：包括此前保留的记录。
- **最近获取**：包含最近一次获取的内容，也可能包含已有记录，不等于只下载新增内容。成功更新后默认选择此项。
- **时间范围**：按原帖发布时间筛选，不是收藏或点赞的时间。只影响下载，不会删除存档。

| 选项 | 内容 |
|---|---|
| 记录文件 | JSON 格式，保存完整记录，便于再次导入和对比。包含正文、昵称和媒体链接；链接不等于实际媒体文件。 |
| 表格文件 | CSV 格式，便于在表格中整理和查看。 |
| 阅读文件 | Markdown 格式，便于阅读正文。 |
| 作者头像 | 下载实际头像文件，默认勾选。 |
| 文章配图 | 下载实际图片文件。 |
| 视频动图 | 下载实际视频、GIF 和缩略图。 |

默认选择记录文件和作者头像，会保存一个 ZIP，包含 JSON、下载成功的头像和“打开查看.html”。解压后打开查看页；离线阅读时保留整个解压目录。只有成功下载的媒体才能离线显示。取消全部媒体选项时，按勾选格式分别下载记录文件。

媒体访问需要按需授权。预估大小不是实际下载体积；可选择“估算大小”进一步检查。每个 ZIP 有 2 GiB 上限；流式保存不可用时上限为 50 MiB。过大的选择可能需要分包或单独保存文件。取消或中断不会修改存档；请核对保存结果。

JSON 可以再次导入。CSV 和 Markdown 仅用于阅读或整理。点赞 JSON 使用独立的 `xkeeps-likes` 格式，不覆盖收藏记录。

## 浏览存档

“浏览”页在本地搜索正文、作者或链接，并按时间或文件夹筛选。可以预览视频、下载图片或视频；“下载整条”将记录、头像和媒体一起打包。未保存到本地的媒体预览需要联网。

辅助查看器 `viewer.html` 可以打开 JSON、搜索、筛选和导入更新。它的存档与扩展内存档相互独立；需要查看扩展中的记录时，先下载 JSON，再在查看器中选择该文件。JSON 在浏览器中处理，不上传到项目服务器。

## 定时更新

定时更新标为“实验功能”，默认关闭。收藏和点赞可以分别开启，间隔可选 1、7、30、90 或 180 天，每次最多检查 1 页。任务绑定设置时的 X 账号，Chrome 开着且电脑醒着时才会运行。

不会自动全部更新、下载媒体或重试失败页。账号变化、未完成更新、访问限制和任务冲突可能使本次更新跳过或只保存部分内容。开启时才申请闹钟权限；定时更新不能替代定期下载备份。

## 隐私与数据安全

- 不提供云端账号、存档上传或远程埋点。操作事件只保存在此浏览器，不含账号、正文、搜索词或文件路径；在设置页可查看汇总、导出或清空，每次写入新事件时清理超过 90 天的记录并限制为 5,000 条；没有新的写入时，旧记录可能继续保留。手动采集及主动启用的定时检查会请求 X；查看或备份媒体时浏览器会访问记录的媒体来源。
- 扩展本地存储不是备份。更换浏览器、删除扩展数据或清理浏览器数据前，先导出累计 JSON。
- 不要把含私人书签的 JSON、Cookie、授权头或账号凭据放进代码仓库或公开问题。
- 保留原版扩展和旧 JSON 可以并行对照；回退时切回原扩展，不要先移除仍需保留数据的扩展。

## 开发与验证

无需安装依赖。运行自动化回归：

```bash
node --test tests/*.test.mjs
```

本地浏览器验证可运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8000/tests/browser-storage.html` 检查合成存档 IndexedDB，访问 `http://127.0.0.1:8000/tests/analytics-browser.html` 检查本地埋点存储，或打开 `http://127.0.0.1:8000/tests/extension-fixture.html` 用合成 X 响应走主页面流程。`?scenario=folder-error`、`?scenario=bad-response` 和 `?scenario=download-cancel` 可检查失败反馈；这些测试不会请求 X，也不能替代真实账号验收。

开发者说明见 [维护指南](maintenance.md)。本版本优先在 macOS 本地 Chrome 验收，Windows 尚未实机验证。
